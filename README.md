# Il Veliero Porticello

A responsive website and digital menu for **Il Veliero**, a bar, sandwich shop,
and drink venue on the Porticello waterfront in Santa Flavia, Sicily.

**Live site:** [ilvelieroporticello.com](https://ilvelieroporticello.com/)

## Paid client project

Frank Smith III was contracted and paid to create this website. The source
material consisted of photographs of the establishment's printed menu and
venue rather than structured content or design files.

The delivery process included:

- extracting menu categories, item names, ingredients, and handwritten prices
  from photographed pages;
- manually reviewing the extracted content against the original images;
- translating the printed menu's navy, yellow, rope, and maritime identity into
  a responsive digital experience;
- adding Google Maps and a direct Google review action;
- generating a downloadable QR code that points to the final domain;
- publishing the source through GitHub and deploying the production site;
- connecting and validating the custom domain and DNS records.

## Customer features

- Mobile-friendly menu categories and item cards
- Venue photography and waterfront presentation
- Direct directions through Google Maps
- Direct Google review link for the verified place
- Downloadable, print-ready QR code
- Custom production domain with SSL
